Dependances installees ou mises a jour pendant la correction
============================================================

Contexte
--------
Ces changements ont ete faits pour corriger :
- les erreurs de type Nuxt
- les warnings de build lies a Tailwind/Vite
- le warning Node 24 DEP0155 visible apres `npm run build`

Dependances ajoutees
--------------------

1. vue-tsc
   Commande :
   `npm install -D vue-tsc`

   Pourquoi :
   - Nuxt s'appuie dessus pour le vrai typecheck des fichiers `.vue`
   - sans lui, `npx nuxi typecheck` n'etait pas proprement exploitable dans ce repo
   - il a permis de valider et corriger les erreurs TypeScript dans les pages/composables

2. @tailwindcss/postcss
   Commande :
   `npm install -D @tailwindcss/postcss`

   Pourquoi :
   - le projet utilisait Tailwind via le plugin Vite
   - ce montage faisait remonter des warnings de sourcemap au build
   - on a bascule Tailwind sur le plugin PostCSS dans `nuxt.config.ts`
   - cette dependance etait donc necessaire pour garder Tailwind actif sans ces warnings

Dependance mise a jour
----------------------

3. vue-router
   Commande :
   `npm install vue-router@5.0.3`

   Pourquoi :
   - le projet etait en `vue-router` 4.x
   - le typecheck Nuxt/Volar attendait ici un alignement avec `vue-router` 5
   - cette mise a jour a supprime le bruit de typecheck lie aux types de routes/SFC route blocks

Ce qui n'a PAS ete corrige par une dependance
---------------------------------------------

Le warning Node 24 `DEP0155` n'a pas ete regle en installant un package supplementaire.

Cause :
- il venait de `@vue/shared` utilise dans la toolchain Nuxt/Nitro
- sous Node 24, l'export wildcard `./*` de ce package declenchait une depreciation pendant le build

Solution appliquee :
- ajout du script `scripts/fix-node24-deprecations.mjs`
- execution automatique dans `postinstall`

But :
- reappliquer le correctif apres chaque `npm install`
- garder `npm run build` silencieux sans modifier le code applicatif

Notes utiles
------------
- `package-lock.json` a change a cause de ces installs/mises a jour.
- `@tailwindcss/vite` etait deja present avant; il n'a pas ete ajoute pendant cette correction.
- il reste dans `package.json`, mais la config utilise maintenant `@tailwindcss/postcss`.
